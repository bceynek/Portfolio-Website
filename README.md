# Babur Ceynek — Portfolio Website

My personal portfolio website, showcasing my projects, technical skills, experience, and interests. I'm a Computer Science student at Stevens Institute of Technology pursuing a minor in Cybersecurity.

## Features

- An introduction and overview of my background.
- Sections for skills, work experience, leadership, and awards.
- Featured projects with descriptions and technologies used.
- Personal interests, including anime, gaming, and soccer.
- Contact links for getting in touch.
- A responsive layout and animated canvas background with support for reduced-motion preferences.

## Built With

- **HTML** for page structure and content.
- **CSS** for styling and responsive layouts.
- **JavaScript** for the canvas animation and interactive effects.

The website uses plain HTML, CSS, and JavaScript, with no framework or build step required.
